日期：2026-10-06。状态：三轮检测完成；所列测试范围内无剩余功能阻断。

## 第一轮：实现与边界

85 项离线回归检测通过，Codex skill-creator 结构校验通过。覆盖标识符与引用、分页/部分失败、PDF/JATS、论断与来源哈希、综述/审稿台账、技术与生物重复、配对/批次、qPCR、原始计数模型、FDR、时间/组内关联、基因集背景、44 原生数据库路由、等位基因/组装、只读查询、凭据头隔离、压缩响应上限、研究规划和稿件草稿状态。

这类检查验证已实现的契约，不构成整个科学领域或所有可能输入的认证。

## 第二轮：实际流程与外部接口

合成常规实验包含 18 个生物学单位、3 个特征、9 个预设比较；完成本地分析、3 幅 PNG/SVG 图和真实后续检索。3 个 Notebook 代码单元实际执行并重算。检查图中生物重复点、n、均值/区间、轴标签和裁剪；这些演示不包含真实用户研究结果。

对 44 个数据库各执行一次有限公开查询：42 个返回成功，其中部分是明确标注的连接/元数据检查，详见 database-checks.json。不能由此推断所有端点、检索完整性、认证或长期可用性。

- CIViC：本机 TLS 连接提前结束，未降低证书校验，保留连接失败。
- eQTL Catalogue：官方已停用 REST API。旧请求明确返回停用状态，另提供通过回归检测的本地 TSV/TSV.GZ 筛选入口。[官方数据说明](https://www.ebi.ac.uk/eqtl/Data_access/)
- 最终数据驱动示例的 4 次逻辑查询全部成功（UniProt、Reactome、两次文献检索），状态为 `retrieval_completed_requires_evidence_reading`；查询成功并不表示论断得到支持。
- 实际试用促成并验证了 FinnGen 字段、Genebass 压缩与关联数组、RefSNP API 路径修复；ChEMBL 重试成功，ENCODE 使用具体公开对象查询成功。
- Elsevier/Wiley 的认证下载与 Paperclip/Scansci 服务未配置凭据，未宣称实测认证成功。

## 第三轮：独立使用与发布审阅

由独立上下文审阅者使用自建合成材料执行验收，没有提供预期答案。发现的四个问题均已修复，并用原触发材料复测：

1. 原始计数必须在技术重复聚合前逐单元格检查，防止小数、负数或缺失被求和掩盖。
2. 长表中样本清单声明的样本若完全没有测量行，拒绝继续推断；须明确缺失或形成有依据的新纳入版本。
3. 复现脚本在重写绝对输入路径前核对冻结配置哈希，配置被改动时停止。
4. Reactome 对 UniProt accession 使用 `data/mapping/UniProt/{accession}/pathways`，带显式 species 参数；同一 GPX4/P36969 自动链实测返回 HTTP 200 与 7 条人类通路。[官方接口](https://reactome.org/dev/content-service)

对应回归测试纳入上述 85 项。独立审阅者重新运行原计数、缺失样本、配置篡改与 GPX4 情景，四项均解除阻断。正常计数、qPCR 与复现仍成功；GPX4 续跑不重复消耗查询预算，缓存哈希保持一致。

独立使用还覆盖：三组合成 qPCR 的效应、95% 区间、p 与 BH q 对照 SciPy/statsmodels，差值小于 1e-10；组学低检出率筛选；批次完全混杂和未知生物学单位拦截；六类真实公共数据库协议；八类写入/越界输入在发网前拒绝；真实论文 JATS 读取；计划与证据关联稿件正反流程。Notebook 实际执行，PNG 抽查无明显排版问题。未宣称复杂纵向模型、受限认证或全部论文图像完成验收。

已知第三方比较集包含 182 个本地文件（旧复用文件及学术技能说明）。检查未发现逐文件哈希相同项，也未发现连续 60 个非注释 Python token 的相同窗口。发布目录检查未发现内嵌 vendor、依赖二进制、原始论文/研究资料、私人绝对路径或匹配的凭据模式。最终文件哈希列于 source-manifest.json。
