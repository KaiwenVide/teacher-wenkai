# 从问题到可审阅研究项目

`study-plan QUESTION --out NEW_DIR [--analysis ANALYSIS_DIR]` 创建研究阶段、实验设计、论文结构和论断表。连接分析时重新核对结果清单、配置和原始输入哈希；只有通过原质量筛选的候选能进入规划。记录的是探索性候选，不是结论。

实际执行顺序：

1. 把问题拆为对象、比较、可观察结果与边界，明确可证伪条件。查找最新原始证据，而不是只收集同方向论文。
2. 完成 evidence_matrix：每行写论断、直接证据/外推/反证、来源定位、模型、时间、测量、效应和局限；记录纳排标准与缺失材料。
3. 比较竞争解释，先选一个能改变判断的最小实验。写清生物学单位、主终点、时间、对照、随机化、盲法、排除、缺失、多重检验、停止规则和样本量依据；不自动设定通用 n。
4. `experiment-check experiment-plan.json` 检查关键项是否有实质决策和审阅声明；通过只表示结构完整，不保证统计功效或实验有效。
5. 由 Codex 根据证据写入 manuscript-plan.json，逐节声明 claim_ids。未实施方法写成计划，实际 Methods/Results 只引用真实完成部分；未核实引用使用明确占位符。
6. `manuscript-build manuscript-plan.json --claims claims.json --out NEW_DRAFT.md` 输出稿件和证据映射。它不会自动生成事实或将草稿升级为发表就绪，内容蕴含关系仍要逐句核对。
7. 按研究类型调整论文、综述、开题方案、基金思路或答审信结构；当前期刊/基金要求须查官方来源。需要评审时冻结材料后调用评审流程。

答审修改需提供具体改动、正文位置和证据理由。没有做过的新增实验不能写成已完成；无法回应的意见清楚说明限制。
