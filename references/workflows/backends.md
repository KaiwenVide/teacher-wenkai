# 外部服务与运行环境

检索、来源核验、合法下载、阅读包、数据库接口和数据分析的项目逻辑在本仓库内实现。Python 科学计算和 PDF 库是独立安装依赖，使用各自的许可；本项目不把它们打包或改称自有代码。

Paperclip 的私有语料、临床/监管资料服务仍需要用户独立安装 CLI 并完成合法认证。本技能只提供明确的检索子命令桥接；运行前用其当期帮助确认参数，从实际返回的语料路径检索并保留行号，不猜文件名。原文证据与服务生成的摘要分开。不自动上传用户材料。

Scansci 请求生成器只准备合法获取参数，须由宿主核对当前 MCP schema 后实际执行；准备请求不等于下载完成。未安装时使用原生 `download`。

机构登录、出版商访问挑战由已授权的宿主浏览器处理。无需复制 Cookie 或自动处理验证挑战。Scopus/WoS 等订阅检索必须有实际访问条件，不能把公开接口结果冒充订阅库的结果。

`doctor` 区分本地依赖和凭据变量是否存在，既不读取凭据文件，也不证明认证或网络访问成功。
