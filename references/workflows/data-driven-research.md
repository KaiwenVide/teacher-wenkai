# 从实验信号自主开展后续研究

本模式的授权是用户在当前研究任务中要求“分析并据此继续 research”。无需为每条普通公开查询重复确认。此授权不自动创建定时任务、新聊天、上传原始实验资料、外发消息或执行真实实验。

## 实际执行

1. 读取 [实验数据](experimental-data.md)，先完成可辨识的设计与 QC。`data-research CONFIG --out NEW_DIR` 会执行分析、筛选信号、UniProt ID 查询、唯一同物种基因解析、Reactome 注释和两个方向的文献查询，保存实际响应。`research-followup ANALYSIS_DIR` 续跑；不能把待执行计划写成已研究。
2. 查看 `research/signals.json`、`evidence-cards.json`、`state.json` 和 `research-brief.md`。默认 3 个去重信号、12 次逻辑查询、每来源每查询最多 6 条论文；可由 research.max_signals（≤10）、max_queries（≤50）、papers_per_query（≤20）及 sources 调整。逻辑查询不等于 HTTP 次数，文献搜索可能要查询及读取详情。失败也消耗预算。
3. 继续阅读返回的真实摘要和原始资料；最重要的 1–3 篇用已有全文下载/精读流程获取上下文与图表。识别研究模型、物种、刺激、时间窗、干预方向、混杂和阴性结果。查询命中、通路成员和蛋白互作都不能直接标记 supported。
4. 根据已读取内容填写 `assets/templates/data-hypothesis-card.json`：数据定位、可证伪问题、方向性假设、直接证据、跨模型外推、反证、竞争解释、关键缺口、最小判别实验、预期可区分结果。为具体支持性表述提供相邻一手来源链接和原文定位。先方向/目标依赖验证，再决定是否展开更多通路分支。
5. 若有会改变结论的明确缺口，再做至多一轮聚焦检索，说明新增查询与信号的关系，保存到研究工作区。不要自动扩展成无边界综述。达到用户预算、连续一轮无新增关键证据、关键设计信息缺失或原文不可达，就交付已得结果与可明确回答的下一步。

## 信号选择及认识边界

- 差异信号：已测试、满足 q/预设效应阈值、无低检出或单点反转等标记。同特征跨比较去重；查看全部三组数据，不能只挑有利两组。
- 趋势：通过估计的组内时间斜率，有 q 值；不是 time×treatment 交互或因果时间顺序证明。
- 关联：同组/时间/批次，至少 8 个完整单位、|rho|≥默认 .6 且 q 过阈值。仍是探索性，近似 p 值与数据驱动选择都需独立验证；不能沿着每条相关边推导通路。
- 重复最小值、批次、缺失、零方差、样本不足与模型失败保留在结果中。质量受限信号不自动提升为机制线索。无合格信号时解释不确定性/检出边界并提出补测；不偷偷放宽阈值寻找故事。

## 公开检索与续跑

物种来自 study.organism/taxon_id；没有明确物种就不做基因数据库解析。study.feature_namespace='gene_symbol'，或提供可信 symbol 列后才自动按基因解析。自动 UniProt 查询先限定 reviewed 条目，再核对唯一同物种 primary gene name；无匹配或多匹配都不猜，转为待映射状态。reviewed 中未查到不等于基因不存在。UniProt/accession 与 Ensembl 默认先保留公开 ID 用于文献，复杂映射读取 [数据库路由](life-sciences.md)。蛋白组/同名基因/跨物种匹配有歧义时停在 unresolved，不能挑第一个结果。

对非基因实验读数，显式配置 `research.feature_terms`，例如 `{"IL6_ELISA":{"public_term":"interleukin 6","gene_symbol":"IL6"}}`。`research.public_context` 只写允许外发的公开疾病/模型词，不能复制私有摘要、样本 ID、原始值或未发表实验条件。缺少公开实体映射时分析仍完成，自动研究显示无合格候选并要求补充映射。

检索默认公共来源 pubmed/europepmc。查机制、干预及无效结果时使用不同查询目的；检索结果仍须逐条判断，不假定“反证查询”的命中就是反证。数据源之间复述同一研究不是独立证据。

成功/失败请求均按内容哈希保存，重复运行不重复查询。`--retry-failed` 只重试失败/部分请求并消耗剩余预算；若预算用尽应明确结束，新的研究问题用有新依据的新分析配置。输入文件或保存的配置改变后拒绝沿用旧结果。`--offline` 保留 pending，联网后同一命令可继续；完成检索仍标记“待证据精读”，只有 Codex 实际读文并填好卡片后才完成综合结论。
